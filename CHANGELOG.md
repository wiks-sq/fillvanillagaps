# Changelog

## 1.1.0-beta.1+26.4-snapshot-7

Beta port to the Minecraft **26.4-snapshot-7** test build (Fabric API 0.165.4+26.4). No feature changes. Snapshots change every week, so this build may not load on other 26.4 snapshots. For normal play, use the 26.3 release.

- Updated for 26.4's new HUD element and screen event signatures and the removal of `Mth.clamp`.

## 1.0.0+26.3

First release for Minecraft 26.3: inventory and chest sorting, a saturation HUD and food tooltips, right-click harvest, tree felling, vein mining, fast leaf decay, a 39-level anvil cap, double doors, safe death drops, Feather Falling crop protection, Infinity + Mending and rotten flesh → leather (both toggleable data packs), and terracotta slabs and stairs.
