# Security policy

## Supported versions

Only the latest release for the newest supported Minecraft version receives fixes.

## Reporting a vulnerability

Don't report security problems in a public issue. That includes anything a player could abuse on a multiplayer server, such as item duplication, crashing a server, or bypassing protections. Instead, report it privately through **[GitHub's private vulnerability reporting](https://github.com/wiks-sq/fillvanillagaps/security/advisories/new)**.

Please include steps to reproduce it. You'll get a reply within a week.
